# Лабораторная работа № 1 — метрики Холстеда для Java

Проект содержит графический Java-анализатор и анализируемую консольную
программу `SampleStatistics.java` объемом 90–100 строк.

## Требования

- JDK 17 или новее;
- сторонние библиотеки **не нужны**.

## Компиляция

Из каталога проекта выполните:

```bash
javac --release 17 -encoding UTF-8 -d build \
  HalsteadMetrics.java JavaHalsteadAnalyzer.java HalsteadAnalyzerApp.java
```

## Запуск графического интерфейса

```bash
java -cp build HalsteadAnalyzerApp
```

Нажмите «Открыть Java-файл», выберите `SampleStatistics.java`, затем нажмите
«Рассчитать метрики».

## Консольная проверка анализатора

```bash
java -cp build HalsteadAnalyzerApp --analyze SampleStatistics.java
```

## Запуск анализируемой программы

```bash
javac --release 17 -encoding UTF-8 -d build SampleStatistics.java
printf '4 7 -2 9 6\n' | java -cp build SampleStatistics
```

Ожидаемые основные строки результата:

```text
Массив: [4, 7, -2, 9, 6]
Сумма: 24
Минимум: -2
Максимум: 9
Среднее: 4.8
Четных: 3
Категория: положительное
```

## Правила подсчета

- пробельные символы и комментарии не учитываются;
- ключевые слова Java, знаки операций и разделители считаются операторами;
- пары `()`, `[]`, `{}` учитываются как один оператор;
- имя метода перед `(` учитывается одновременно как оператор вида `имя()`
  и как операнд `имя`;
- остальные идентификаторы и литералы считаются операндами;
- шесть базовых метрик: `η1`, `η2`, `N1`, `N2`, `f1j`, `f2i`;
- три расширенные метрики: `η = η1 + η2`, `N = N1 + N2`,
  `V = N × log2(η)`.
