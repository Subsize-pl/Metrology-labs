# Лабораторная работа № 2а — метрика Джилба (Java)

Анализатор считает для текста на Java **абсолютную сложность CL**, **относительную сложность
cl = CL / N** и **максимальный уровень вложенности CLI**, выводит таблицу ветвлений, таблицу
операторов и синтаксические ошибки.

| Файл | Назначение |
|---|---|
| `OrderStats.java` | анализируемая программа (всё в `main`): for, for-each, while, do-while, if / else if / else, switch, вложенные ветвления |
| `GilbAnalyzer.java` | разбор (javac Compiler Tree API) и подсчёт метрик |
| `GilbAnalyzerApp.java` | окно Swing |
| `GilbAnalyzerTest.java` | проверки: примеры методички, switch, крайние случаи, `OrderStats.java` |
| `Отчет_ЛР2а_Java.docx` | отчёт: код, схема алгоритма по ГОСТ 19.701-90, ручной расчёт, скриншот |

## Запуск (JDK 21+)

```bash
javac -encoding UTF-8 -d build *.java
java -cp build GilbAnalyzerApp            # окно, сразу открывает OrderStats.java
java -cp build GilbAnalyzerTest           # проверки
```

## Правила подсчёта

- **CL** — каждый `if` (и каждый `else if`), каждый цикл, каждая метка `case`.
- **switch** заменяется цепочкой вложенных `if`: k-я метка `case` лежит на уровне (уровень switch + k − 1),
  селектор и `default` условиями не считаются (switch из n ветвей → n − 1 условий, вложенность n − 2).
- **CLI** — внешнее ветвление на уровне 0, тело ветвления и его `else` — на уровень глубже.
- **N** — операторы по JLS, гл. 14: объявления локальных переменных, выражения-операторы, `if`, `switch`,
  циклы, `break`, `continue`, `return`, `throw`, `try`. Не считаются: объявления класса/метода, `{ }`,
  метки `case`/`default`, заголовок `for`, комментарии. `?:`, `&&`, `||` — не ветвления.
- Если текст не разбирается как файл, он читается как набор операторов (можно вставить кусок кода).

## OrderStats.java

CL = 16, N = 51, cl = 16 / 51 = 0,314, CLI = 5 (`if (amount < 500)` внутри `case 3`:
for → if → case 1 → case 2 → case 3 → if).
